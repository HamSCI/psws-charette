
# Python API for Doppler, level and frequency spread computations
## Description
Yes please! I have to stress how brilliant the existing quick look spectrograms and digital RF data are. But I'd so like to automate, especially across the midnight boundary so I can easily see local-noon centred plots.
I'd appreciate professionally coded simple analysis tools in Python - my amateur efforts are at https://github.com/g3zil/grapeDRF_doppler_model 
encompassing Doppler shift, level and frequency spread when the spectrogram is unimodal, and the far more difficult tasks of assigning and tracking Doppler shifts when multiple co-propagating modes are present.
