
# Automated QA metadata
## Description
A metadata file for the GRAPE instruments (of all types / generations) that would be created automatically from appropriate data analysis to note artefacts such as: frequency offset(s) e.g. from uncalibrated sound card clock in the direct conversion GRAPEs, spectral lines from fundamental or harmonics of local well controlled sources, e.g. from TCXOs, OCXOs etc at the WWV frequencies, harmonics of the Doppler traces e.g. from receiver overload, an issue for the first year or more with RX888 Mk2 SDRs at several sites until Rob Robinett & Phil Karn between them sorted out the two-stage AGC and 32 bit float.
