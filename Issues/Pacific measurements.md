                # Description
                Please keep the existing PSWS data, graphics and amplitude charts, especially for the Russian 'K' CW beacon on 7039.3 kHz. This is the only 24/7 Asian Pacific coast beacon that we monitor for studies of trans-North Pacific US-to-Asia HF 40m radio propagation. There is very little Pacific Ocean propagation data, and no Pacific Ocean ionosondes, so these images and data are very important to our studies.
Thanks, and 73,
Larry Serra N6NC
