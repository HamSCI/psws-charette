
# Auto feedback to stations on data quality
## Description
This is related to my auto QA feature, with this feature being to close a feedback loop to the station operator. The current database holds much data with artefacts that either compromises data analysis or makes it more difficult or time consuming. Quick feedback to station operators and checks that the causes have been corrected would be great.
